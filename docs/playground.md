# Try the Playground / 在线体验

Explore three deliberately constructed, repository-owned examples without installing Reforge. Each scenario includes its complete source, configuration, review question, reasonable exceptions, and an interactive report.

无需安装 Reforge，即可查看三个由本仓库自有、特意构造的示例。每个场景均提供完整源码、配置、审查问题、合理例外和交互报告。

[Open the bilingual Playground / 打开双语在线体验](playground/)

Analysis runs during the documentation build. The Playground has no backend, uploads no code, and does not scan or evaluate third-party repositories.
