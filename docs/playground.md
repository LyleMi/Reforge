# Try the Playground / 在线体验

Review three deliberately constructed agent patches without installing Reforge. Each scenario compares a real before/after repository fixture, explains the repository's existing convention, and presents the single Issue generated from the after state.

无需安装 Reforge，即可审查三个由本仓库自有、特意构造的 Agent patch。每个场景都对比真实 before/after fixture，说明仓库原有约定，并展示 after 状态产生的唯一 Issue。

[Open the bilingual Playground / 打开双语在线体验](playground/)

The documentation build verifies that every before state has zero Issues and every after state has exactly one expected Issue. The Playground has no backend, uploads no code, and does not scan or evaluate third-party repositories.
